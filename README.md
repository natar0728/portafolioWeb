# Portafolio personal — Hazell Reyes

Página personal desarrollada para la asignatura
Diseño de sistemas en Internet.

## Objetivo

Aplicar la estructura básica de HTML mediante una página
que presente mi perfil, habilidades, imagen y enlaces
a sitios de interés.

## Tecnologías utilizadas

- HTML5: estructura y contenido.
- CSS3: diseño visual y adaptación a dispositivos móviles.
- JavaScript: animaciones y actualización del año.

## Contenido

- Presentación personal.
- Habilidades e intereses.
- Proyectos académicos.
- Enlaces a recursos de aprendizaje.

## Archivos

- index.html: página principal.
- styles.css: estilos.
- script.js: comportamiento y animaciones.
- img/perfil.jpg: imagen de perfil.

## Etiquetas HTML utilizadas

html, head, body, h1, h2, h3, p, ul, li, img y a.

También se emplearon header, nav, main, section,
article, figure, figcaption y footer.

## Ejecución local

1. Descargar o clonar el repositorio.
2. Abrir index.html en un navegador.

No requiere instalación de dependencias.
